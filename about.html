A useful note

Know what happens behind the scenes.

Different media tasks have different technical demands. A little context helps you get the best out of the tools.

Image processing

Processing behavior depends on the specific tool and browser support. Check each tool's guidance before working with sensitive or important files.

Video processing

Video conversion and export can use significant memory and processing power. Shorter clips and moderate output settings may work better on less powerful devices.

Keep a backup

Before editing an important original, keep a separate copy. Available features and supported formats can vary by browser and device.
